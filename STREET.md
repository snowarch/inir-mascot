# Street line (drop 2026-07-17)

Second art line for Kira: modern smooth anime, casual streetwear (oversized
tees, purple hoodie, cat-print clothes, leg warmers, sneakers), messy hair,
occasional heterochromia. Generated by the maintainer, ingested from the
private source sheets. Same character identity
(blonde + ahoge, tan cat ears/tail, cat hair clip, choker, hoop earrings),
different rendering style from the classic pixel-art line — pools that rotate
automatically should not mix busts into full-body slots, and edgy art stays
out of automatic rotation entirely.


Ratings: `safe` (automatic rotation ok), `dark` (deadpan dark humor — context
pools only, e.g. late night / crash), `edgy` (smoking/alcohol/rude gesture —
manual override and collection only, never automatic).
